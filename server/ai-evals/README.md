# NEXA AI evaluation datasets

These fixtures are synthetic and approved for evaluation/training-package preparation only. They are not user exports and must not be replaced with raw private conversations.

Each profile has its own dataset and its version advances when cases materially change. Live balances, orders, payments, identities and Staff records are represented as retrieval/tool-routing cases rather than memorized facts.

B342 prepares provider-neutral training packages with a SHA-256 integrity hash. It does not submit a live external training job. Candidate promotion requires a passing evaluation and is owner-controlled; rollback remains available.
