## Layer model
- Environment: contextual local artwork / future high-fidelity AI wallpaper slot.
- Depth: runtime 3D-like rings, glass and light using existing dependencies.
- Motion: existing server-resolved subscription tier + reduced-motion authority.

## Subscription visual policy
- Free: environment + depth, static.
- Regular: environment + depth + existing intentional motion.
- Premium: Regular plus ambient world/depth motion.
- VIP: Premium plus VIP spotlight.

These visual entitlements do not grant any protected product capability.
