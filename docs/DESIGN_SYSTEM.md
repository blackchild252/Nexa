# NEXA Main — Design System Roadmap Companion

- **Visual identity:** NEXA brand; keep marketplace/customer surfaces warm, clear and commerce-oriented. Do not reuse Central’s governance look as a substitute for NEXA branding.
- **Typography:** system sans-serif/Inter fallback; 12–14px supporting text, 16px default body, 20–24px section headers, responsive display titles.
- **Spacing:** 4/8/12/16/24/32px scale; consistent card padding, form gaps and screen-edge safe areas.
- **Sections:** consumer home, marketplace search/categories, product detail, cart/checkout, vendor products/orders/disputes/staff, Customer Care and Zeeza inbox.
- **States:** loading, empty, error, offline, disabled, success, pending review, rejected and escalated. Status cannot rely on color alone.
- **Accessibility:** accessible names, large touch targets, keyboard focus, screen-reader order, contrast, reduced motion and form validation hints.
- **Roadmap:** detailed implementation is registered under Main M7241–M7265; current evidence queue M7116–M7165 remains first.
