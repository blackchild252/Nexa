# Project Memory Protocol

`PROJECT_MEMORY.json` is the durable project-level memory contract for the App Builder.

Update it when any of the following materially changes:
- active architecture;
- current release/version;
- design system;
- important security constraints;
- release/test state;
- external validation blockers;
- major architectural decision.

Do not store secrets, passwords, API keys, access tokens, private credentials, or personal data in project memory.

Historical implementation reports remain evidence. Project memory is the concise current state, not a replacement for history.
