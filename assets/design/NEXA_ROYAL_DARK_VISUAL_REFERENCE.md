# NEXA Royal Dark — Visual Reference

This concept image is the **official visual north-star reference** for the NEXA Royal Dark design language.

It is a design reference, not a screenshot or a claim that every screen is pixel-identical to the concept.

## Core direction

- Deep black / graphite foundations
- Royal Gold `#D4AF37` as the signature accent
- Bright-gold highlights for active and primary actions
- Warm ivory typography for high-contrast hierarchy
- Gold-accented borders and restrained glow
- Elevated, rounded surfaces with clear depth
- Native, simple iconography
- Dark status/navigation surfaces
- Smooth transitions and focused five-destination navigation
- Dami/NEXA AI presented as a premium centerpiece

## Reference intent

Use this image when evaluating future UI work for:

1. Overall visual mood and premium feel
2. Gold/black/ivory balance
3. Card, button, input and navigation treatment
4. Visual hierarchy and spacing
5. Consistency across Home, Marketplace, AI, Search, Profile and supporting routes

## Important implementation rule

The reference must guide the interface without overriding accessibility, platform conventions, performance, security, or existing product functionality.
