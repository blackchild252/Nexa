# NEXA Home Screen Design — Version 1

Status: CANONICAL / APPROVED

## Home composition
- Royal Gold Dark visual identity remains the permanent theme.
- Home does not contain feature tiles/cards for Sky Money, Dream Marketplace, Yaayz, L.A., Ball House, Kitchen, Game House, Fitness, or other destination modules.
- Those destinations are accessed from the collapsible vertical NEXA directory/sidebar.
- Market Watch remains a thin live horizontal rail at the top; it is not a destination tile/grid.
- NEXA Updates remains a thin activity rail below Market Watch.
- Dami is the primary visual focus of Home with motion enabled according to the existing NEXA motion tier.
- Bottom interaction is balanced as three anchors: Zeeza Friends (left), Dami (center), Calls Audio/Video (right).
- The top-right menu opens the vertical directory and can be closed by the X, backdrop, or Close Menu row.

## Naming
- Dami = NEXA AI.
- Zeeza = People/Social, including Friends, Inbox, Rooms, and Calls.

## Reference image
`NEXA_HOME_DESIGN_V1_APPROVED_REFERENCE.png` is the visual reference used for future Home refinements.

## Future changes
Future Home changes should extend this composition deliberately and create a new version entry rather than silently restoring the old heavy destination grid.
