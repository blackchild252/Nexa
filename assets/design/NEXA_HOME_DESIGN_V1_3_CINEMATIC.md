# NEXA Home Design V1.3 — Cinematic Environment

Status: CANONICAL VISUAL REFINEMENT
Release: 5.22.0 / Batch B58 / Milestone 304

## Purpose

V1.3 closes the first audited gap between the approved Home references and the active runtime without changing the Home command-center structure.

## Preserved composition

- NEXA header + collapsible directory
- Market Watch rail
- NEXA Updates rail
- Dami as the single visual centerpiece
- Zeeza Friends at lower left
- Calls at lower right
- No destination tile/grid surface

## Royal Dark environment

The Home base environment now uses the bundled `NEXA_HOME_CINEMATIC_BACKGROUND_V1.png` asset. The asset is an environment layer only; it does not contain interactive controls or product data.

The existing `NexaDarkHome` animated layer remains above the environment. Its subscription-tier and reduced-motion rules remain authoritative.

The Dami route intentionally retains `NexaCosmos`; this Home refinement does not merge the Home and Dami environments.

## Visual intent

The V1.3 environment introduces the visual ingredients that were missing from the runtime audit:

- cinematic black/purple/gold sky depth
- dense star field
- distant ringed planet
- large holographic orbital arcs
- warm horizon glow
- NEXA skyline and beacon tower
- layered dark mountain/shore silhouette
- reflective gold water path
- central hero halo/rings behind the Dami position
- restrained vignette for content readability

This is a visual foundation, not a claim of pixel-identical rendering of the conceptual V1.2 reference.
